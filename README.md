## Local maintenance

1. Edit the static files in the repository root and keep local asset references relative, such as `assets/images/example.png`.
2. Run the validation checks described in `TODO.md`, including JSON validation, `node --check script.js`, asset existence checks and a local static preview.
3. Review the public URLs in `sitemap.xml`, `robots.txt`, the canonical tag and social metadata whenever the site URL changes.
4. Commit changes to `main` and push them to GitHub. GitHub Pages then rebuilds automatically from the repository root.

Do not add API keys, payment credentials or private user data to this repository.
